# Documentație

[`ARCHITECTURE.md`](ARCHITECTURE.md) explică modelul general.
[`SOURCES.md`](SOURCES.md) descrie sursele UVABc și regulile de proveniență, iar
[`TERMINOLOGY.md`](TERMINOLOGY.md) stabilește termenii folosiți în cod și în proză.

Detaliile arhitecturale sînt împărțite în:

- [`architecture/CONTENT.md`](architecture/CONTENT.md) — structura conceptuală;
- [`architecture/UNIVERSITY.md`](architecture/UNIVERSITY.md) — programe, discipline
  și profesori;
- [`architecture/CURRICULUM.md`](architecture/CURRICULUM.md) — curriculum, cohorte,
  intrări curriculare și opționale;
- [`architecture/SYLLABI.md`](architecture/SYLLABI.md) — fișele disciplinelor;
- [`architecture/LATEX.md`](architecture/LATEX.md) — generarea documentului;
- [`architecture/IMPLEMENTATION.md`](architecture/IMPLEMENTATION.md) — modulele
  Fennel și validarea.

[`architecture/MIGRATION.md`](architecture/MIGRATION.md) este o notă temporară
despre trecerea de la modelul vechi și poate fi eliminată după terminarea
migrării.

Pentru contribuții, vedeți [`../CONTRIBUTING.md`](../CONTRIBUTING.md).
